# Tests

The test hierarchy contains unit, contract, integration, synthetic, regression, leakage, and performance checks.

Phase 1 starts filling those boundaries with data-foundation tests. The initial slice covers canonical research-bar contracts, provider-adapter structural compatibility, request validation, and deterministic daily-bar quality rules. Later data-foundation slices will add ingestion idempotency, identifier resolution, point-in-time universe, storage/reconstruction, cross-provider reconciliation, and performance coverage.
